## Helpers

The helper API wraps the common end-to-end flows. It is exposed as a reactive store hook in
supported frameworks.

```ts
const { useUploadHelpers } = uploadClient;
const helpers = useUploadHelpers();

await helpers.createUploadAndTransfer(file, {
  provider: "teams",
  fileKey: `teams/${teamId}/logo`,
  onProgress: ({ bytesUploaded, totalBytes }) => {
    console.log(bytesUploaded, totalBytes);
  },
});
```

### `createUploadAndTransfer`

- Creates an upload.
- Streams the file's content to `PUT /uploads/:uploadId/content`, reporting progress, and falls back
  to a buffered request when the browser cannot stream request bodies.
- Returns the published file, or the prepared write for a `batch` upload.

### `downloadFile`

```ts
const response = await helpers.downloadFile(`teams/${teamId}/logo`, { provider: "teams" });
const blob = await response.blob();
```

It reads `GET /files/by-key/content?provider=...&key=...`.
